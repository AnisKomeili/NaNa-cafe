 NaNa Café

NaNa Café یک وب‌سایت مدرن و ریسپانسیو برای یک کافه است که با تمرکز روی طراحی بصری، نمایش منوی محصولات و ایجاد یک تجربه ساده و روان برای کاربران ساخته شده است.

ایده اصلی پروژه این بود که به‌جای یک صفحه ساده و ثابت، یک وب‌سایت کافه با بخش‌های تعاملی و ساختار منظم داشته باشیم؛ از منوی دسته‌بندی‌شده و اسلایدر محصولات گرفته تا فرم تماس و طراحی اختصاصی برای موبایل.

 درباره پروژه

در طراحی NaNa Café از ترکیب رنگ‌های گرم قهوه‌ای و کرمی، تصاویر مرتبط با قهوه و کارت‌های مدرن استفاده شده تا فضای کلی سایت با هویت یک کافه هماهنگ باشد.

ساختار منو به‌صورت داده‌محور طراحی شده است. اطلاعات محصولات در فایل جداگانه نگهداری می‌شوند و JavaScript بر اساس دسته و زیر‌دسته انتخاب‌شده، محصولات مربوط را در صفحه نمایش می‌دهد. به این شکل اضافه یا تغییر دادن محصولات بدون نیاز به تغییر ساختار HTML امکان‌پذیر است.

 بخش‌های اصلی

* صفحه اصلی با Hero Section و معرفی کافه
* معرفی آیتم ویژه روز
* بخش آمار و اطلاعات کافه
* بخش معرفی ویژگی‌های کافه
* منوی دسته‌بندی‌شده محصولات
* دسته‌های Food، Drinks و Dessert
* زیر‌دسته‌های مختلف برای هر گروه
* نمایش محصولات به‌صورت Slider
* کارت‌های دوطرفه برای نمایش اطلاعات و مواد اولیه محصولات
* بخش About
* بخش اطلاعات تماس
* فرم Contact
* پیام موفقیت پس از ارسال فرم
* Footer با لینک‌های اصلی و شبکه‌های اجتماعی
* طراحی Responsive برای دسکتاپ، تبلت و موبایل

## Menu

منوی سایت یکی از بخش‌های اصلی پروژه است و به‌صورت Dynamic پیاده‌سازی شده است.

محصولات در `products.js` نگهداری می‌شوند و هر محصول اطلاعاتی مانند نام، توضیحات، قیمت، تصویر، دسته‌بندی، زیر‌دسته و مواد اولیه دارد.

کاربر می‌تواند ابتدا یکی از دسته‌های اصلی را انتخاب کند و سپس از بین زیر‌دسته‌ها محصولات موردنظر خود را ببیند.

* Food
* Drinks
* Dessert

نمونه زیر‌دسته‌ها

* Breakfast
* Soup
* Salad

کارت محصولات نیز قابلیت Flip شدن دارد و با رفتن به پشت کارت، مواد اولیه آن محصول نمایش داده می‌شود.

 تعاملات و JavaScript

* منوی موبایل و Hamburger Menu
* تغییر وضعیت Active در Navigation
* فیلتر و نمایش Dynamic محصولات
* کنترل Slider منو

* اعتبارسنجی اولیه فرم تماس

 طراحی Responsive

NaNa Café برای اندازه‌های مختلف صفحه طراحی شده است.

در نسخه دسکتاپ، بخش‌هایی مانند Hero، About و Contact دارای چیدمان چندستونه هستند و محصولات و آمار نیز فضای بیشتری در اختیار دارند.

در نمایشگرهای کوچک‌تر، ساختار صفحات تغییر می‌کند تا محتوا خواناتر و استفاده از سایت راحت‌تر باشد. منوی اصلی نیز در موبایل به یک Hamburger Menu تبدیل می‌شود و بخش‌های مختلف صفحه به‌صورت تک‌ستونه نمایش داده می‌شوند.

 تکنولوژی‌ها

ترکیب این فونت‌ها برای ایجاد تفاوت بین تیترها، بخش‌های انگلیسی و محتوای فارسی استفاده شده است.

 وضعیت پروژه

NaNa Café یک پروژه Front-End است و تمرکز آن روی طراحی رابط کاربری، Responsive Design، JavaScript و پیاده‌سازی تعاملات سمت کاربر بوده است.

در نسخه فعلی، سیستم‌هایی مانند سبد خرید، پرداخت آنلاین، حساب کاربری، Backend، Database و ثبت واقعی سفارش پیاده‌سازی نشده‌اند. فرم تماس نیز در حال حاضر در سمت Front-End مدیریت می‌شود و اطلاعات آن به یک سرور واقعی ارسال نمی‌شود.
